# User Requirements

## Functional Requirements

The application should allow **visitors** to:

* Navigate between the main public pages.
* View restaurant information.
* Browse the menu.
* View menu prices.
* View restaurant and food imagery.
* Find the restaurant location.
* Access contact information.

**Authenticated customers** should be able to:

* Register an account.
* Log in and log out.
* Create a booking.
* View their bookings.
* Update their own bookings.
* Cancel their own bookings.
* Add products to a basket.
* Complete an online payment.
* Receive confirmation of successful or unsuccessful actions.

**Administrators** should be able to:

* Manage menu categories.
* Create menu items.
* Update menu items.
* Delete menu items.
* View bookings.
* Update booking information.
* Access protected administrative functionality.

## Non-functional Requirements

The application should:

* Be responsive across common device sizes.
* Follow accessibility principles.
* Provide clear and consistent navigation.
* Validate user input.
* Protect user data.
* Provide appropriate user feedback.
* Handle errors gracefully.
* Follow Django conventions.
* Use a relational database.
* Maintain separation between front-end and back-end code.
* Be suitable for cloud deployment.
